# C++ Assignment: New and Delete Operators

## Aim
To demonstrate dynamic memory allocation using new and delete operators in C++.

## Description
A C++ program to dynamically allocate memory for student marks, calculate total and average marks, and release memory.

## Concepts Used
- Dynamic Memory Allocation
- New Operator (new[])
- Delete Operator (delete[])
- Pointers

## Result
Successfully implemented dynamic memory allocation and deallocation in C++.

C++
