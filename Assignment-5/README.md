# Student Management System Using C++

## Description
A simple menu-driven Student Management System developed in C++ using Object-Oriented Programming (OOP) concepts.

## Features
- Enter and display student details.
- Update student marks using a friend class.
- Display total student objects created.
- Menu-driven interface.

## OOP Concepts Used
- Class and Object
- Default and Parameterized Constructors
- Inline Function
- `this` Pointer
- Static Data Member and Function
- Friend Class
- Encapsulation

## Technologies Used
- **Language:** C++
- **IDE:** Dev-C++ 


## How to Run
1. Open the code in a C++ IDE.
2. Compile and run the program.
3. Choose an option from the menu.

## Conclusion
This project demonstrates important C++ OOP concepts through a simple Student Management System.
