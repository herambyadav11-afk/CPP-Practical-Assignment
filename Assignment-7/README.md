# Runtime Polymorphism Using Virtual Functions in C++

## Description
This project demonstrates runtime polymorphism in C++ using virtual functions and inheritance. It shows how a base-class pointer calls different derived-class functions at runtime.

## Features
- Demonstrates runtime polymorphism.
- Uses virtual functions and function overriding.
- Implements inheritance using Animal, Dog, and Cat classes.
- Uses a base-class pointer to access derived-class methods.

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Runtime Polymorphism
- Virtual Functions
- Function Overriding
- Base-Class Pointer

## Technologies Used
- **Language:** C++
- **IDE:** Dev-C++ 


## Sample Output
```text
Dog barks.
Cat meows.
```

## How to Run
1. Open the C++ file in an IDE.
2. Compile and run the program.
3. Observe the output of runtime polymorphism.

## Conclusion
This program demonstrates how virtual functions enable runtime polymorphism by calling overridden methods through a base-class pointer.
