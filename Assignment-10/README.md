# Class Template in C++

## Aim
To implement a class template in C++ for performing addition and multiplication using different data types.

## Description
This program uses a class template named `Calculator` to perform arithmetic operations on integer and double values.

## Concepts Used
- **Class Template:** Allows a class to work with different data types.
- **Constructor:** Initializes two values.
- **Member Functions:** Perform addition and multiplication.

## Output

```text
Integer Calculator:
Addition = 15
Multiplication = 50

Double Calculator:
Addition = 4
Multiplication = 3.75
```

## Conclusion
Successfully implemented a class template in C++ to perform addition and multiplication using integer and double data types.
