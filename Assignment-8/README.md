# Exception Handling in C++

## Aim
To implement exception handling using `try`, `throw`, and `catch` in C++.

## Description
This program performs division of two numbers and handles division by zero using exception handling.

## Concepts Used
- **try:** Contains code that may cause an exception.
- **throw:** Throws an exception when the denominator is zero.
- **catch:** Handles the exception and displays an error message.

## Output

**Normal Case:**
```text
Enter two numbers: 10 5
Division = 2
Program continues after exception handling.
```

**Exception Case:**
```text
Enter two numbers: 5 0
Exception caught: Division by zero is not allowed.
Program continues after exception handling.
```

## Conclusion
Successfully implemented exception handling in C++ using `try`, `throw`, and `catch`.****
