Aim:
To write a C++ program using STL Vector to store, sort, and reverse elements.

Description:
This program demonstrates the use of the Standard Template Library (STL) in C++. It uses a vector to store integer elements and performs sorting and reversing operations using built-in functions.

Concepts Used:
iostream: Used for input and output operations.
vector: Used to store elements dynamically.
algorithm: Used for sorting and reversing elements.
push_back(): Adds an element to the vector.
sort(): Sorts elements in ascending order.
reverse(): Reverses the order of elements.

Algorithm:

Start the program.
Create an empty integer vector.
Accept the number of elements from the user.
Insert elements into the vector using push_back().
Display the original elements.
Sort the elements using sort().
Display the sorted elements.
Reverse the elements using reverse().
Display the reversed elements.
End the program.

Sample Output:
Enter number of elements: 5
Enter 5 elements:
40 10 50 20 30

Original elements: 40 10 50 20 30
Sorted elements: 10 20 30 40 50
Reversed elements: 50 40 30 20 10

Conclusion:
This program demonstrates how STL Vector can be used to store and manage elements dynamically. It also shows how built-in STL algorithms simplify sorting and reversing operations in C++.
