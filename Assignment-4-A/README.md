# C++ Assignment: Pointers and References

## Aim
To demonstrate the use of pointers and references in C++.

## Description
This program accepts student marks and modifies their value using pointers and references.

## Concepts Used
- Pointers
- References
- Address-of operator (&)
- Dereference operator (*)

## Sample Output
```text
Enter student marks: 85
Marks before using pointer and reference = 85
Address of marks = 0x6ffe2c
Address stored in pointer = 0x6ffe2c
Marks after using pointer = 78
Marks after using reference = 95
```

Note: Memory addresses may vary.

## Result
Successfully implemented pointers and references in C++ to access and modify variable values.
