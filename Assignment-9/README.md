# String Swap in C++

## Aim
To demonstrate how to swap the contents of two strings using the `swap()` function in C++.

## Description
This program demonstrates the use of the `swap()` member function of the C++ `string` class. Initially, `str1` contains `"Hello, C++ Programming"`, while `str2` is empty.

The statement `str2.swap(str1)` exchanges the contents of both strings. After swapping, `str2` contains the original value of `str1`, and `str1` becomes empty.

## Algorithm
1. Start the program.
2. Include the `<iostream>` and `<string>` header files.
3. Initialize `str1` with `"Hello, C++ Programming"`.
4. Display the value of `str1` before swapping.
5. Declare an empty string `str2`.
6. Use `str2.swap(str1)` to exchange the contents of both strings.
7. Display the values of `str1` and `str2` after swapping.
8. Stop the program.




## Concepts Used
- **String:** Used to store a sequence of characters.
- **`swap()` function:** Exchanges the contents of two strings.
- **`cout`:** Displays output on the screen.
- **`endl`:** Inserts a newline and flushes the output stream.

## Result
The program successfully demonstrates swapping the contents of two strings using the `swap()` member function in C++.
