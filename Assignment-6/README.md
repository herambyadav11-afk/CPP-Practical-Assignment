# Types of Inheritance in C++

## Description
This project demonstrates three types of inheritance in C++ using simple examples. It explains how derived classes can access the properties and functions of base classes.

## Types of Inheritance

1. **Single Inheritance:** One derived class inherits from one base class (`Person → Student`).
2. **Multiple Inheritance:** One derived class inherits from two base classes (`Father + Mother → Child`).
3. **Multilevel Inheritance:** A class inherits from another derived class (`Animal → Dog → Puppy`).
